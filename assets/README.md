# Date in-app illustrations

These transparent PNG assets were generated with the built-in image generation tool using `../mascot.jpg` as the character and style reference. The original mascot remains the app logo.

| File | Used in | Prompt direction |
| --- | --- | --- |
| `mascot-heart.png` | Discovery guide, empty My Picks state, and swap success | Same flame-faced mascot joyfully hugging a glossy pink heart, two gold sparkles, isolated transparent sticker. |
| `mascot-trophy.png` | Discovery guide and leaderboard hero | Same flame-faced mascot triumphantly lifting an oversized gold trophy, with small gold sparks, isolated transparent sticker. |
| `mascot-scout.png` | Discovery guide, loading and empty states, early-bird tip, and wallet setup | Same flame-faced mascot scouting with a chunky purple and gold magnifying glass and one gold sparkle, isolated transparent sticker. |
| `mascot-rocket.png` | Live market pulse panel | Same flame-faced mascot joyfully riding a coral-and-gold rocket upward with two small gold sparkles and a short pink flame trail, isolated transparent sticker. |
| `mascot-wallet.png` | Connect Wallet dialog | Same flame-faced mascot holding a glossy purple wallet with one gold sparkle, isolated transparent sticker. |

All prompts asked for the reference mascot's orange, coral, pink, and yellow flame silhouette, winking frog eyes, smile, thick black outlines, glossy 2D finish, full readable character, generous transparent margins, and no text, numbers, logos, watermark, or background. The two newer assets were generated with the built-in image generation tool from `../mascot.jpg` and copied into this directory for use by the app.
